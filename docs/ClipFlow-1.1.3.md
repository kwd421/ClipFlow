# ClipFlow 1.1.3

## 변경 사항

- 예정된 YouTube 라이브/프리미어 링크를 넣으면 오류 대신 "라이브 시작 대기 중" 행으로 표시하고, 방송이 시작되면 자동으로 처음부터 다운로드합니다. 앱이 켜져 있어야 동작합니다.
- 라이브 다운로드 중 받은 시간과 현재 방송 길이를 표시합니다. (예: 라이브 녹화 · 8:20 / 1:02:05)
- 브라우저 쿠키를 선택한 상태에서 방금 시작한 YouTube 라이브가 "The page needs to be reloaded."로 분석·다운로드되지 않던 문제를 수정했습니다. 이 경우 쿠키 없이 다시 시도합니다.
- Bilibili 다운로드를 병렬 구간 요청으로 빠르게 받도록 개선했습니다.
