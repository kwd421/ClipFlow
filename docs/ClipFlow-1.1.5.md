# ClipFlow 1.1.5

## 변경 사항

- YouTube 채널 감시를 추가했습니다. `https://www.youtube.com/@채널/live` 주소를 넣고 다운로드하면 "채널 감시 중"으로 대기하다가, 채널이 라이브를 시작할 때마다 처음부터 자동으로 녹화합니다. 같은 방송은 한 번만 녹화하며, 감시 행을 지우면 감시가 멈춥니다. 앱이 켜져 있어야 동작합니다.
- 다른 링크를 분석하면 라이브 시작 대기 행이 사라져 대기가 취소되던 문제를 수정했습니다.
- 코덱을 직접 지정했을 때 낮은 화질(예: 144p AV1)이 선택되던 문제를 수정했습니다. 이제 화질이 코덱보다 우선하며, 코덱은 같은 화질 안에서 우선합니다.
