# ClipFlow 1.1.8

## 변경 사항

- 자동 라이브 타겟에 Instagram 계정을 추가할 수 있습니다(`instagram.com/아이디`). 5분마다 라이브 여부를 확인하고, 라이브가 시작되면 처음부터 녹화합니다. Instagram에 로그인된 브라우저 쿠키가 필요합니다.
- Instagram 라이브 링크(`instagram.com/아이디/live/...`)를 직접 넣어도 처음부터 녹화합니다. 녹화 중 받지 못한 구간은 방송이 끝난 뒤 다시 받아 채웁니다.
- 분석 중에 앱을 닫거나 분석을 취소할 때 분석 작업이 멈추지 않던 문제를 수정했습니다.
