# ClipFlow 1.1.1

## 변경 사항

- Windows 배포 파일을 NSIS 설치형으로 변경했습니다. 이후 업데이트는 기존 설치 경로의 앱을 교체합니다.
- 업데이트 직후 이전 앱의 임시 실행 폴더를 재사용해 Python DLL 오류가 발생하던 재시작 문제를 수정했습니다.
- 연속으로 링크를 붙여넣고 다운로드할 때 분석 대기열이 입력칸을 덮어쓰거나 다운로드가 누락되는 문제를 수정했습니다.
- YouTube에서 원본 음성 트랙 표시가 제공되는 경우 더빙 대신 원본을 선택하도록 수정했습니다.
- HLS 다운로드 후 MP4 컨테이너 정리를 복원하고, 받지 못한 조각을 건너뛰어 불완전한 파일을 완료 처리하지 않도록 변경했습니다.
- Windows 파일 보기의 탐색기 경로 인용 처리를 수정했습니다.
- YouTube 라이브 조각 처리 및 진행 표시를 개선했습니다. 실제 방송 종료 전후의 모든 상황에 대한 보장은 아닙니다.

## 설치 안내

- 기존 단독 실행형 EXE 사용자는 설치형으로 한 번 전환한 뒤 시작 메뉴의 ClipFlow를 실행하세요.
- 1.0.10과 1.1.0 사이에 Windows 업데이트 서명 키가 변경되었습니다. 1.0.10에서 서명 검증 오류가 발생하면 새 설치 파일을 직접 설치해야 합니다.
- 설치 및 제거는 다운로드 영상과 앱 설정/히스토리를 삭제하지 않습니다.
